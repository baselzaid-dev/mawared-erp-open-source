# Contributor Code of Conduct

## Our pledge

We aim to make participation in this project a respectful, constructive experience for everyone.

## Expected behavior

- Be respectful, considerate, and constructive.
- Welcome questions from contributors of all experience levels.
- Critique code and ideas, not people.
- Handle disagreements professionally and help resolve them constructively.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information without permission.
- Deliberate intimidation, trolling, or repeated disruptive conduct.

## Enforcement

Report concerns privately to the repository owner through GitHub. Reports will be reviewed as fairly as possible. The project does not currently have a separate moderation team.
