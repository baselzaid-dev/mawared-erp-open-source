# Mawared ERP

> **Release preparation in progress.** This repository is currently private and does not yet contain the reviewed application source. Do not treat it as a complete or production-ready release.

Mawared ERP is an ERP platform under development, intended to bring together human resources, attendance, leave management, procurement, and multi-company operations through an Android application and backend services.

## Planned technology stack

- **Android:** Kotlin and Jetpack Compose
- **Backend:** TypeScript, Express, and Prisma
- **Database:** PostgreSQL

These technologies and the feature scope must be verified against the source code before the public release is marked complete.

## Security notice

Do not add API keys, passwords, private keys, production database connection strings, customer information, database exports, or production logs to this repository. Use local environment files and provide only redacted example configuration.
