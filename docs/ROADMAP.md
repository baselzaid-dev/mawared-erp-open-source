# Roadmap

## Before publication

- Close or explicitly triage dependency and security findings.
- Verify guarded setup, PostgreSQL migrations, and Android builds from a fresh runner.
- Complete third-party attribution and contribution provenance review.
- Confirm a private vulnerability-reporting channel and enforce branch review rules.

## After a first community release

- Document client coverage by workflow and expand cross-tenant regression fixtures.
- Publish an API reference derived from verified route contracts.
- Add packaging and self-hosting examples for independently owned infrastructure.
- Improve accessibility and Arabic and English localization coverage.
- Define a maintained upgrade policy and release cadence.

Current source functionality is listed in the [README](../README.md).
